# Canteen Sales Tracker

## 1. Project Description

The Canteen Sales Tracker is a Python-based application developed using Streamlit and OpenPyXL. The application allows users to upload an Excel workbook containing canteen orders and automatically processes the sales information.

It calculates total sales, identifies the best-selling item, provides summary statistics, and displays charts to help users understand sales performance across different campuses and product categories.

The application also identifies invalid orders, skips incorrect records, and displays a warning indicating how many records were rejected.

## 2. Technologies Used

The application was developed using:

- **Python:** Main programming language.
- **Streamlit:** Used to create the interactive web application.
- **OpenPyXL:** Used to read and process Excel workbooks.
- **Python Lists and Dictionaries:** Used to store, organize and calculate sales information.

## 3. Application Features

The Canteen Sales Tracker includes the following features:

1. **Excel File Upload:** Allows users to upload an Excel workbook containing canteen orders.
2. **Data Processing:** Reads Excel records and converts each order into a Python dictionary.
3. **Sales Calculations:** Calculates the total for each order using Price × Quantity.
4. **Invalid Record Detection:** Identifies, skips and counts invalid orders.
5. **Campus Filter:** Allows users to filter orders by campus.
6. **Category Filter:** Allows users to filter orders by product category.
7. **Summary Statistics:** Displays total sales, number of orders and average order value.
8. **Best-Selling Item:** Identifies the item with the highest quantity sold using a dictionary.
9. **Order Details Table:** Displays the filtered orders, including their calculated totals.
10. **Sales Histogram:** Displays the distribution of order totals using J$500 ranges.
11. **Sales by Item Chart:** Displays the total sales revenue generated by each item.

## 6. Installation Requirements

The following software must be installed:

- Python 3
- Streamlit
- OpenPyXL

Install the required Python libraries by opening a terminal in the project folder and running:

```bash
pip install -r requirements.txt
```

The `requirements.txt` file contains:

```text
streamlit
openpyxl
```

## 7. How to Run the Application

Follow these steps:

**Step 1:** Open the project folder in Visual Studio Code or a terminal.

**Step 2:** Open the terminal in the project directory.

**Step 3:** Install the required libraries:

```bash
pip install -r requirements.txt
```

**Step 4:** Start the Streamlit application:

```bash
streamlit run app.py
```

**Step 5:** Open the local address displayed in the terminal, usually:

```text
http://localhost:8501
```

**Step 6:** Upload the `canteen_orders.xlsx` file using the file uploader.

The application will automatically process the orders and display the sales information, summary statistics, filters and charts.

## 8. Data Validation

The application checks uploaded orders to ensure that the Price and Quantity fields contain numerical values.

Records containing invalid price or quantity information are skipped and counted.

A warning is displayed to inform the user how many invalid orders were excluded from the calculations.

Completely empty rows are also skipped during data processing.
